## 2026-09-18 — экраны мастерской (волна M2b)

Статус сборки: код собран, проверки зелёные; в игре ещё не проверялась.

- [ ] Alt+B открывает мастерскую, рассказчик не переключается; клавишу видно и можно переназначить в «Управлении».
- [ ] Лента: поиск, фильтры (в том числе «Больше фильтров»), сортировка с кареткой, переключатель размера карточек.
- [ ] Карточки: обложка, ▶ с кольцом превью, значки, статус-пилюля, точки сложности, наведение показывает статистику
      и полосу кнопок, через 100 мс раскрывается список сложностей.
- [ ] Прокрутка ленты подгружает следующую страницу и не дёргается на масштабах GUI 2–4 и «Авто».
- [ ] Страница карты: обложка, плитки сложностей, кнопки ♥ / «Установить» / «Открыть в браузере» / ⋯, правая колонка
      со статистикой, шкалами и оценкой (10 сегментов) — и всё это в русском языке.
- [ ] Комментарии: список, сортировка, голос, ответ, жалоба, удаление своего; Ctrl+Enter отправляет.
- [ ] Вкладка «Установленные»: карточки из локальных данных, обновление, «Отозвана», удаление, «Открыть папку»,
      «Скопировать в мои треки», «Выбрать файл музыки» для карт без музыки, импорт .blockymap и папка «входящие».
- [ ] Аккаунт: вход через Minecraft и по коду, «Запомнить меня», «Это не я», привязка аккаунта с подтверждением,
      уведомления, выход.
- [ ] Мастер загрузки: выбор треков, сложности, музыка/обложка, описание, публикация; строки этапов показывают
      байты, отмена работает, после успеха есть «Открыть страницу карты» и «Установить».
- [ ] В библиотеке треков появилась вкладка «Установленные карты», а у локального трека — выбор
      «Опубликовать на сервере / в мастерской».
- [ ] Ничего не пишется за пределами папки игры: «Запомнить меня» лежит в
      `music_battle_tracks/.account/session.json`.

## 2026-09-17 — массовое подключение проводом

Статус сборки: готова к ручной проверке, в папку игры не установлена.

- [ ] Провод в руке развёрнут от игрока правильной стороной в виде от первого лица.
- [ ] Провод правильно развёрнут в руке другого игрока; иконка в инвентаре не изменилась.
- [ ] ПКМ по нескольким колонкам добавляет каждую из них в список провода.
- [ ] ПКМ по нескольким камерам добавляет каждую из них в тот же список.
- [ ] Колонки и камеры можно выбрать одновременно.
- [ ] Повторный ПКМ по выбранной колонке или камере убирает её из списка.
- [ ] ПКМ по DJ-панели подключает весь список за одно нажатие.
- [ ] После массового подключения список провода очищается.
- [ ] Если сначала выбрать DJ-панель, следующие колонки и камеры подключаются сразу,
      а панель остаётся выбранной для дальнейшей работы.
- [ ] Shift + ПКМ по колонке отключает её, как раньше.
- [ ] Shift + ПКМ по камере отключает её от выбранной DJ-панели, как раньше.
- [ ] Shift + ПКМ в воздух очищает текущий список или выбранную DJ-панель.
- [ ] Shift + ПКМ по обычному блоку или сущности не очищает выбор провода.
- [ ] Подсказка предмета показывает количество выбранных колонок и камер.
- [ ] Объекты дальше 64 блоков, удалённые объекты и переполненная панель пропускаются
      без сбоя остальных подключений.
- [ ] После массового подключения появляется понятный итог: сколько объектов подключено
      и сколько пропущено.
